# GPT Configuration

This directory contains the version-controlled backup of the fields manually configured in the **Software Engineering Method Custom GPT**.

- `instructions.md`: GPT instructions
- `description.md`: GPT name and description
- `conversation-starters.md`: conversation starters

ChatGPT remains the place where the Custom GPT is configured. These files preserve a Git backup of the corresponding fields; they do not prove which values are currently deployed.
